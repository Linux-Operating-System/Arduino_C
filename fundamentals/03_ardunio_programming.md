# Arduino Programming

This section focuses on Arduino programming concepts and hardware interaction.

---

# 📚 Topics Covered

- setup() and loop()
- pinMode()
- digitalWrite()
- digitalRead()
- analogRead()
- PWM
- Serial Communication
- Interrupts

---

# 💻 Example

```c
void setup() {
    pinMode(13, OUTPUT);
}

void loop() {
    digitalWrite(13, HIGH);
}
```
