# Hardware Requirements

This guide explains the hardware components required for learning Arduino programming and embedded systems.

---

# 📦 Basic Components

## 1️⃣ Arduino Board

The Arduino board is the main microcontroller board used for programming and hardware interaction.

### Recommended Boards
- Arduino UNO
- Arduino Nano
- Arduino Mega

### Suggested for Beginners
✅ Arduino UNO

---

# 🔌 USB Cable

A USB cable is required to:
- Upload code to Arduino
- Provide power
- Enable serial communication

### Cable Type
- USB Type-B (Arduino UNO)
- Mini USB / Micro USB (Nano clones)

---

# 🧩 Breadboard

A breadboard allows circuit building without soldering.

### Recommended
- 400 tie-point breadboard
- 830 tie-point breadboard

---

# 🔗 Jumper Wires

Used to connect components together.

### Types
- Male to Male
- Male to Female
- Female to Female

---

# 💡 LEDs

LEDs are used for beginner projects and output visualization.

### Recommended Colors
- Red
- Green
- Blue
- Yellow

---

# ⚡ Resistors

Resistors protect components from excessive current.

### Common Values
- 220Ω
- 330Ω
- 1kΩ
- 10kΩ

---

# 🎛 Sensors

Sensors help Arduino interact with the environment.

### Recommended Beginner Sensors
- Ultrasonic Sensor (HC-SR04)
- DHT11 Temperature Sensor
- PIR Motion Sensor
- IR Sensor

---

# 🖥 Display Modules

Display modules are used to show information.

### Common Modules
- 16x2 LCD Display
- OLED Display

---

# ⚙ Motors

Motors are used in robotics and automation projects.

### Recommended
- Servo Motor (SG90)
- DC Motor
- Stepper Motor

---

# 🔋 Power Supply

Required for powering Arduino and external components.

### Options
- USB Power
- 9V Battery
- External Adapter

---

# 🧰 Recommended Starter Kit

A beginner Arduino starter kit should include:
